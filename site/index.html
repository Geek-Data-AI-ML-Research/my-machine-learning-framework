Version 0.1.0. A local toolkit for ML and Kaggle contests. It keeps one experiment ledger, checks blends and submissions, and gives a coding agent a memory of what already failed.

Python 3.11 or newer. One user. No account, no model host, and no call to Kaggle or a cloud provider.

install 
pip install -e .
python -m mymlfw version

The core install covers the ledger, GroupKFold, blends, the submit gate, the kernel builder, five engines, cloud script rendering, and retrieval. A real backward pass needs pip install -e '.[train]'.

first contest 
python -m mymlfw new-contest demo --dest .
python -m mymlfw probe register \
  --ledger demo/ledger/experiments.csv \
  --experiment-id exp_001 \
  --baseline-id base \
  --variable lora_r=16 \
  --band-low 0.70 \
  --band-high 0.80
python -m mymlfw analyze --dir demo

analyze prints JSON and writes nothing unless you pass --out. next_steps holds at most five items.
