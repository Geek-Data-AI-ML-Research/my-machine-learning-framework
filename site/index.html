What it does

Keep the campaign honest

mymlfw is the process boundary around a contest: register probes, blend OOFs, refuse bad submissions, and brief the next agent turn.

  • One experiment ledger

    Every probe names one variable and a score band. Duplicates and closed probes are refused before you waste a run.

  • Blend and submit gates

    Align predictions, optimize weights, then preflight hashes, leak checks, and offline kernels before anything leaves the machine.

  • Agent memory

    Recipes, dead ends, and episodes stay retrievable. Advise writes a worktree brief; the agent records the outcome later.

The loop

From probe to next step

A single CLI process. Failures are one JSON object on stderr with an error code and a suggested fix.

  1. Probe

    Register the change, update CV, score public, set a verdict. The ledger is the source of truth.

  2. Blend

    Optimize OOF weights, check diversity and shift, diagnose folds before you promote a stack.

  3. Gate

    Preflight blocks closed probes, hash mismatches, and kernels with internet on.

  4. Advise

    Retrieve recipes and past lessons into a git worktree brief. Record the episode after you run.

Campaign SaaS

Studio when the campaign outgrows a single folder

Optional Docker stack: API, Studio console, MCP for agents, Mongo, Redis, and object storage — all bound to localhost until you connect cloud runners.

Start

Install and scaffold a contest

Python 3.11+. Local by default — no account required for the core toolkit.

Clone the repo, install the package, then create a contest directory with an empty ledger and preflight script.

Full walkthrough: First contest · Docs index 

git clone https://github.com/Geek-Data-AI-ML-Research/my-machine-learning-framework.git
cd my-machine-learning-framework
python -m venv .venv
.venv/bin/pip install -e .
.venv/bin/python -m mymlfw version
.venv/bin/python -m mymlfw new-contest demo --dest .

For coding agents

Built to be driven by an IDE agent

Read the machine index first, then the binding rules — not a wall of markdown.

  • llms.txt + AGENTS.md Command map and non-negotiable rules (call run_oof, don’t invent folds).
  • JSON failures Every CLI error is one object with error_code and suggested_fix.
  • Five engines TextBlend, RankedCandidate, AgentZip, Portfolio, Benchmark — matched from recipe cards.
  • MCP Studio sync Keep roadmap, dead ends, and levers updated from the agent without pasting screenshots.
